# ACH Client: instaladores e atualizações

Distribuição do ACH Client para Windows x64, com suporte a Minecraft 1.21.11 e 26.2.

[Baixar o instalador atual](https://github.com/romaoficialtt-collab/ach-client-releases/releases/latest/download/ACH-Client-Setup-win-x64.exe)

Instale este pacote uma vez para receber o sistema de atualização. Depois, o ACH verifica novas versões ao abrir. Use **Atualizar agora** para baixar e instalar. Se o Minecraft estiver aberto, termine a partida e use **Instalar atualização**.

Mundos e configurações ficam preservados. Se a conexão falhar, você pode continuar usando a versão instalada.

As entregas ficam em [Releases](https://github.com/romaoficialtt-collab/ach-client-releases/releases). Este repositório contém somente documentação de instalação, binários e metadados de atualização. Os arquivos JSON são usados pelo verificador do launcher; não precisam ser instalados manualmente.
